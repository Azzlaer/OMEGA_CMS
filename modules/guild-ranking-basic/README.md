# Guild Ranking Basic v1.0.0

Módulo público para Omega MU CMS.

## Ruta

```text
/rankings?type=guilds
/rankings?type=guilds&view=basic
```

No aparece en Mi Cuenta.

Cuando está activo, convierte el ranking de clanes en una vista modular básica.

## Datos

READ ONLY:

- Guild
- GuildMember

## Compatibilidad con Professional

Si también se instala:

`Guild Ranking Professional`

ambos aparecen dentro de Rankings como:

```text
🏰 Básico
✨ Profesional
```
